# Рабочий сайт «Баловень» на GitHub Pages

`site/` в этой папке — опубликованная версия сайта с cafe-baloven.com, подготовленная для GitHub Pages. Она включает основные страницы, афишу, карточки событий, меню, контакты и документы. Корневые `site/` и `source/` репозитория относятся к первоначальному портфолийному проекту.

- GitHub Pages обслуживает содержимое этой папки `site/` из ветки `gh-pages`.
- Рабочий домен остаётся на Tilda. Бронирование и заявки отправляются только через оригинальные формы на сайте кафе.
- Билеты, видео и отзывы открываются на тех же внешних площадках, что и на рабочем сайте. Изображения и оформление используют опубликованные ресурсы Tilda.
- Афиша и меню отражают состояние на дату выгрузки, указанную в `site/assets/export-manifest.json`. Изменения на Tilda не попадают в GitHub Pages автоматически.
- Сбор статистики рабочего сайта не переносится в GitHub Pages. Локальные черновики, заявки и резервные копии не входят в выгрузку.

Обновление выгрузки: запустить `node production/export.mjs /путь/к/новой-папке` из корня репозитория, проверить страницы, заменить снимок `production/site/` и синхронизировать ветку `gh-pages`. Скрипт проверяет наличие ключевых страниц и соответствие публичной афиши карте сайта. Недельное меню проверяется отдельно перед публикацией.
